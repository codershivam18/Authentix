# Authentix
Beat ATS, Detect AI, and Sound Human.

Authentix is a premium, high-performance web application designed to help professionals and academics navigate automated systems.

## Features
- **ATS Analyzer**: Optimizes resumes against job descriptions using the STAR method.
- **AI Detection**: Analyzes text for AI generation markers and provides a strict academic integrity report.
- **Text Humanizer**: A stealth writing tool that bypasses AI detectors by maximizing burstiness and perplexity while stripping AI vocabulary.
- **IEEE Citation Generator**: Converts messy URLs and references into strictly formatted IEEE citations.

## Tech Stack
- **Frontend**: HTML5, Vanilla JavaScript, Tailwind CSS (Glassmorphism design).
- **Backend**: Python, Flask, Gunicorn.
- **AI Engine**: Groq Cloud API (running `llama3-8b-8192` for lightning-fast streaming).
