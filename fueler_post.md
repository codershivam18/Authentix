# 🚀 Fueler Project Title:
Authentix: Premium AI Detection, ATS Optimization & Academic Text Humanization Platform

# 🌟 Short Description:
A high-performance, dark-mode web application built with Flask, Groq API, and Vanilla JS. Authentix is designed to help professionals and students bypass ATS systems, detect AI footprints in academic papers, and humanize text using stealth rewriting algorithms.

# ✍️ Full Description (For the Post Body):
Welcome to **Authentix**, a premium tool built for the modern academic and professional landscape. I built this application to solve the growing problem of AI detection and Applicant Tracking Systems (ATS) blocking real talent.

Using the lightning-fast **Groq API** running **Llama-3-8B**, Authentix provides a suite of elite tools with real-time streaming interfaces:
- 📈 **ATS Resume Optimizer**: Upload your resume and job description, and the AI automatically rewrites your bullet points using the STAR method, injecting high-impact action verbs and ATS-friendly keywords.
- 🕵️ **AI Detection & Academic Integrity**: Run any text through the engine to get a calculated AI Probability Score and a detailed IEEE-standard markdown report on stylistic anomalies.
- 🎭 **Stealth Text Humanizer**: Bypasses classic AI detectors by maximizing sentence "burstiness" and "perplexity" while stripping out overused AI vocabulary (like "delve" or "moreover").
- 📚 **IEEE Citation Generator**: Instantly restructures messy URLs and reference lists into strict, bracketed IEEE formats.

**Tech Stack Breakdown:**
* **Frontend**: HTML5, Vanilla JavaScript, Tailwind CSS (Custom CSS Variable-based Dark/Light mode & Glassmorphism UI)
* **Backend**: Python, Flask, Gunicorn
* **AI Engine**: Groq Cloud API (`llama3-8b-8192`)
* **Deployment**: Dockerized for Hugging Face Spaces
